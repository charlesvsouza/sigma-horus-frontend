# Fontes do certificado de presença

Embutidas no PDF gerado no servidor (`src/lib/certificate-pdf.ts`, carregadas por
`src/lib/certificate-server.ts`; incluídas no bundle via `outputFileTracingIncludes` no
`next.config.ts`).

- **Cinzel Decorative Bold** — título e nome do irmão. Licença SIL OFL 1.1 (`OFL-CinzelDecorative.txt`).
- **Cormorant Garamond** Regular/Bold/Italic (versões estáticas do repositório original,
  github.com/CatharsisFonts/Cormorant) — texto. Licença SIL OFL 1.1 (`OFL-CormorantGaramond.txt`).

Nenhuma das duas tem o "∴": ele é desenhado com três pontos no PDF.
